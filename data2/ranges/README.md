Diese Dateien sind die gebündelte Datenbasis für spätere Zeitraum-Auswahlen.

`management/manifest.json` beschreibt den verfügbaren Bereich.
`management/overview.csv` enthält den täglichen Gesamtmarkt-Verlauf je Kraftstoff.
`management/brand_prices.csv` enthält tägliche Markenverteilungen.
`management/hourly_deltas.csv` enthält die stündlichen Management-Kennzahlen je Tag.
`management/reference_histograms.csv` enthält die täglichen 12:00-Referenz-Histogramme.
